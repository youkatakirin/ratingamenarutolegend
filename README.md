# Рейтинг Immortal · Naruto Legend 3.0

Сайт с таблицей лидеров и историей рейтинговых матчей Immortal. Данные берутся из канала #результаты-immortal на Discord-сервере Naruto Legend 3.0.

- `index.html` — весь сайт: таблица лидеров, матчи, профили игроков, герои, тир-листы, рекорды. Данные сезона лежат внутри него в блоке `<script type="application/json" id="season-data">`, всё остальное считается из списка матчей.
- `heroes/` — портреты героев 64×64 в WebP, имя файла — имя героя латиницей (`Рок Ли` → `heroes/rok-li.webp`, правило — функция `heroSlug` в коде). Взяты со страницы героев ac.narutolegend.dog и пересохранены, чтобы сайт не зависел от чужого репозитория с картинками. Портреты показываются в таблице, матчах, профилях, банах, тир-листах и на картинке тир-листа. Аватарка игрока — портрет героя, на котором он сыграл больше всего игр (при равенстве — больше побед); пока героев нет — первая буква ника.
- `heroPool` в данных сезона — все герои карты (список с ac.narutolegend.dog). Из него берутся герои для конструктора тир-листа; если на карте появится новый герой, допиши его сюда (герои из матчей добавляются и сами).
- Вкладка «Герои» — статистика каждого героя (игры, винрейт, частота пика, средние У/С/П, урон, урон по зданиям, полученный урон, крипы, MVP/SVP, кто играл) и тир-лист по формуле: оценка = 70% сглаженного винрейта (победы + 2) / (игры + 4) + 30% вклада в команду (доля урона по героям, по зданиям и участия в убийствах; 1,00 — средний игрок, тоже сглаживается). Тиры: S от 62, A от 55, B от 47, C от 40, D ниже; в тир-лист попадают герои от 2 игр. Параметры — объект `HT` в коде.
- Вкладка «Тир-лист» — конструктор для посетителей в двух режимах, «Игроки» и «Герои»: перетаскивание (на телефоне — нажать на карточку, потом на тир), автосохранение в браузере, ссылка (`#tier~…` / `#tierh~…`) и картинка PNG.
- У игрока в матче могут быть поля `hero`, `kda` [убийства, смерти, помощь], `cs`, `gold`, `dmg`, `lvl` (с ac.narutolegend.dog), `award` (MVP/SVP), `tdmg` (урон по башням) и `taken` (полученный урон) — последние три со скриншота итогов. У матча — `src` (номер матча на ac.narutolegend.dog), `duration`, `kills` [Альянс, Акацуки].
- `shots/game-N.jpg` — скриншоты итогов матчей.
- `cards/game-N.png` — карточки итогов матча для Discord и соцсетей: `python3 tools/make_card.py index.html N` рисует карточку и ставит матчу поле `card` (шрифты в `tools/fonts`, лицензия SIL OFL).
- Правила рейтинга лежат в блоке `<script type="application/json" id="rules-data">`, у каждого пункта свой номер (например `2.3`). Пометки у игрока (`note` + `rule`) и у матча (`note` + `noteRule`) ведут на пункт правил.
- `tools/season.py` — достать данные из страницы или записать их обратно.

### Как считаются очки
- Организатор пишет обычные очки за игру (+20 / −20, у команды вылетевшего −10 / +30 по пункту 4.4). Бонусы за серии и штрафы вручную не пишутся — их считает сайт.
- Серии (пункты 11.2–11.3): с 6-й победы подряд каждая следующая +5, с 6-го поражения подряд −5.
- Блокировок нет (пункт 12.1 с 30.10.2026): штраф у игрока в матче — поле `ban: {reason, rule, points}`, по умолчанию −20, размер задаёт `points` (от −20 до −100). Штраф вне матча — запись в `penalties`: `{date, p, reason, rule, points, match}`. У ливнувшего (пункт 4.6) `d: 0` — он получает только штраф.
- MVP и SVP матча получают +5 (пункт 11.4, по голосованию, с первой игры сезона: `points.awardFrom` = 1), размер — `points.award`. Сайт и карточки добавляют это сами.
- Герои круга и позора отменены (пункт 11.5).
- `log` в данных сезона — записи вкладки «Логи»: `{date, kind: rules|fix|note, text, rule?, match?}`; штрафы попадают туда сами.
- `og.jpg` — картинка для превью ссылки, рисуется `python3 tools/make_og.py og.jpg`.
- Сайт публикует GitHub Pages: https://youkatakirin.github.io/ratingamenarutolegend/ — обновляется сам после каждого push в main. `.nojekyll` отключает обработку Jekyll.
- `netlify.toml` — старый адрес nlrating.netlify.app переадресует на GitHub Pages; сборки на Netlify пропускаются, если этот файл не менялся.

Очки: победа +20, поражение −20, MVP/SVP +5, серия ±5 (с 6-й игры подряд), штрафы −20…−100.

Как обновлять сайт вручную — `UPDATING.md`.
