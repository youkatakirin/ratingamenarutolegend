# Рейтинг Immortal · Naruto Legend 3.0

Сайт с таблицей лидеров и историей рейтинговых матчей Immortal. Данные берутся из канала #результаты-immortal на Discord-сервере Naruto Legend 3.0.

- `index.html` — весь сайт: таблица лидеров, матчи, профили игроков, рекорды и герои сезона. Данные сезона лежат внутри него в блоке `<script type="application/json" id="season-data">`, всё остальное считается из списка матчей.
- У игрока в матче могут быть поля `hero`, `kda` [убийства, смерти, помощь], `cs`, `gold`, `dmg`, `lvl` (с ac.narutolegend.dog), `award` (MVP/SVP), `tdmg` (урон по башням) и `taken` (полученный урон) — последние три со скриншота итогов. У матча — `src` (номер матча на ac.narutolegend.dog), `duration`, `kills` [Альянс, Акацуки].
- `shots/game-N.jpg` — скриншоты итогов матчей.
- `cards/game-N.png` — карточки итогов матча для Discord и соцсетей: `python3 tools/make_card.py index.html N` рисует карточку и ставит матчу поле `card` (шрифты в `tools/fonts`, лицензия SIL OFL).
- Правила рейтинга лежат в блоке `<script type="application/json" id="rules-data">`, у каждого пункта свой номер (например `2.3`). Пометки у игрока (`note` + `rule`) и у матча (`note` + `noteRule`) ведут на пункт правил.
- `tools/season.py` — достать данные из страницы или записать их обратно.

### Как считаются очки
- Организатор пишет обычные очки за игру (+20 / −20, у команды вылетевшего −10 / +30 по пункту 2.2). Бонусы за серии и штрафы за баны вручную не пишутся — их считает сайт.
- Серии (пункт 8.1): с 6-й победы подряд каждая следующая +5, с 6-го поражения подряд −5.
- Бан у игрока в матче — поле `ban: {reason, rule}`; сайт снимает −20 (пункт 8.5) и считает срок по пункту 2.6: 1-я блокировка 1 день, 2-я 2 дня и т. д., счётчик у каждого игрока свой и обнуляется после каждых 50 сыгранных им игр (начало сезона — первое обнуление). У ливнувшего (пункт 2.3) `d: 0` — он получает только −20. Можно переопределить `days` и `points` (например −50 по пункту 6.4).
- Бан вне матча — запись в `penalties`: `{date, p, reason, rule}` (+ `days` / `points` при необходимости).
- MVP и SVP матча получают +5 (пункт 8.3, по голосованию) — с игры `points.awardFrom`, размер — `points.award`. Сайт и карточки добавляют это сами.
- Герои круга и позора отменены (пункт 8.4).
- `og.jpg` — картинка для превью ссылки, рисуется `python3 tools/make_og.py og.jpg`.
- Сайт публикует GitHub Pages: https://youkatakirin.github.io/ratingamenarutolegend/ — обновляется сам после каждого push в main. `.nojekyll` отключает обработку Jekyll.
- `netlify.toml` — старый адрес nlrating.netlify.app переадресует на GitHub Pages; сборки на Netlify пропускаются, если этот файл не менялся.

Очки: победа +20, поражение −20, MVP/SVP +5, серия ±5 (с 6-й игры подряд), блокировка −20.

Как обновлять сайт вручную — `UPDATING.md`.
